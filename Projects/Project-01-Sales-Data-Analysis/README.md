# Sales Data Analysis

This project analyzes sales data to identify useful business insights and understand sales performance.

## Objectives

* Analyze total sales
* Identify top-performing products
* Compare sales across regions
* Find monthly sales trends
* Generate useful business insights

## Tools

* Excel
* Data Analysis
* Data Visualization

## Key Analysis

The dataset will be cleaned and analyzed to understand sales performance and identify important patterns.
